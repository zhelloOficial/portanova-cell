# Portanova Cell · Black Friday

Landing da Black Friday da Portanova Cell (celulares, acessórios e assistência técnica, Curitiba). Feita pela Zhello.

```bash
npm install
npm run dev   # http://localhost:3220
```

Next.js 16 + Tailwind 4, página estática. Links de WhatsApp, Instagram, endereço e avaliações ficam em `src/lib/loja.ts`.
